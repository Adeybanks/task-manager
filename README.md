# Task Manager App

A simple web app to manage your tasks.

## Features
- Add tasks with priority (low/medium/high).
- Edit or delete any task.
- Calendar tab: View tasks by month or year.

## How to Use
1. Type a task and pick priority.
2. Click "Add".
3. Use calendar to check tasks.
4. Edit or delete as needed.
